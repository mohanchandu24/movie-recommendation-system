# Movie Recommendation System 

## Overview
This project is a Hybrid Movie Recommendation System built using Machine Learning techniques on the TMDB 5000 Movies dataset.

The system recommends similar movies based on content similarity and classification models.

## Problem Statement
Users often struggle to find movies matching their interests.  
This system recommends movies based on similarity using NLP and ML techniques.

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-Learn
- TF-IDF Vectorization
- PCA (Dimensionality Reduction)
- SMOTE (Handling Class Imbalance)
- KNN
- Random Forest



## Machine Learning Workflow

1. Data Cleaning & Preprocessing
2. Feature Engineering (TF-IDF)
3. Dimensionality Reduction using PCA
4. Class Balancing using SMOTE
5. Model Training (KNN & Random Forest)
6. Model Evaluation
7. Movie Recommendation Generation



## Dataset
TMDB 5000 Movies Dataset
